# Overview

FinRisk AI Platform is an enterprise-grade AI-powered fraud detection and financial risk intelligence system built using:

* React.js
* Flask
* Machine Learning
* JWT Authentication
* Real-Time Analytics
* Explainable AI
* Ensemble Fraud Detection
* Live Monitoring Dashboards

The platform simulates how modern fintech companies monitor suspicious financial transactions, detect anomalies, analyze fraud behavior, and provide explainable AI insights.

# Installation

## Clone Repository

```bash

```

---

## Frontend Setup

```bash
cd frontend
npm install
npm start
```

## Backend Setup

```bash
pip install -r requirements.txt
python run.py
```
